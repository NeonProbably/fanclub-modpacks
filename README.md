# CU-Online
Finally got this shit done, so unlike the other branches I'm gonna just include a basic "how to add" and some tips

-HOW TO ADD MODS FROM THE GIT-
- replace the contents of the mods folder with the ones from the branch, then run the game.
(or hit refresh ingame)

-TIPS-
- Visit the Mod config in the options, will let you tweak gameplay settings or mod settings if you hover over a mod and press the jump key (Z)
- Turn off Chez's Tweaks, for your sake and mine.
- The game tends to crash without a message in online, it's just a desync issue, can't combat this yet.
